# משחק לימוד אותיות - אלף בית

משחק אינטראקטיבי ללימוד אותיות האלפבית העברי לילדים בגילאי 5-7.

## תכונות עיקריות

- לימוד אותיות האלפבית העברי בצורה חווייתית
- משחק התאמה עם תמונות וצלילים
- ממשק ידידותי לילדים
- אנימציות ופידבק חיובי
- תמיכה מלאה בעברית

## דרישות מערכת

- Node.js גרסה 14 ומעלה
- npm גרסה 6 ומעלה

## התקנה

1. התקן את התלויות:
```bash
npm install
```

2. הפעל את הפרויקט:
```bash
npm start
```

3. פתח את הדפדפן בכתובת:
```
http://localhost:3000
```
